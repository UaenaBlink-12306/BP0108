# BP0108 Question Additions

When adding livestream questions to this project:

- Use subagents to help draft or review large question batches.
- Add cartoon-style images for every new question ID.
- Keep the strongest identifying or giveaway wording in the final two sentences of each question.
- Store newly added livestream questions as two display-ready sentences unless the user asks otherwise.
- Match the existing `stream_questions_100.json` item schema unless the runtime is intentionally updated.
